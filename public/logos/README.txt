Déposez ici les logos officiels des moyens de paiement.

Fichiers attendus (exactement ces noms) :

  wave.png            → le logo officiel Wave (pingouin sur fond bleu)
  orange-money.png    → le logo officiel Orange Money (flèches sur fond orange)

Dès que ces fichiers sont présents, ils s'affichent automatiquement
partout dans l'application (sélecteur de paiement, flyers) et dans le
flyer imprimable /flyer-gestionpro.html.

Tant qu'un fichier est absent, un repli propre (badge de marque) est
affiché à la place — aucune image cassée.

Format conseillé : PNG carré (≥ 256×256) à fond plein, ou SVG.
